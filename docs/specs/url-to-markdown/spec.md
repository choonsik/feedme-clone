# URL → Markdown → LLM

웹 페이지 URL을 붙여넣으면 본문만 Markdown으로 뽑아 보여 주고, 복사·다운로드하거나 ChatGPT·Claude로 바로 넘기는 서비스.

Linked sources:
- [docs/decisions/ui-composition.md](../../decisions/ui-composition.md): 화면 구성(shadcn 기반 컴포넌트, 공통 shell, 상태 설계, 좁은 화면)을 따른다.
- [docs/decisions/dependency-versions.md](../../decisions/dependency-versions.md): 새 의존성을 추가할 때 버전 정책을 따른다.
- [prototype.html](prototype.html): 승인된 화면 구성과 아이소매트릭 시각 스타일(입력, 결과, 내보내기, 프롬프트 선택, 오류·긴 글 상태, 다크모드). 화면 배치, 상태별 안내 문구, 블록 질감과 색의 기준이다. 가짜 데이터와 가짜 동작은 구현 대상이 아니다.
- [docs/decisions/visual-language.md](../../decisions/visual-language.md): 아이소매트릭 시각 언어의 규칙(블록 면, 색 묶음, 입력창에만 쓰는 글자 그림자)을 정한다. 이 spec은 그 규칙을 다시 적지 않는다.
- 변환 라이브러리: defuddle (https://defuddle.md/docs). 사용자가 필수로 지정했다.

## 사용자에게 보이는 결과

1. **입력**: 화면 상단에 URL 입력창이 있다. 붙여넣고 변환을 실행한다. 지우기 버튼을 누르면 입력과 결과가 모두 처음 상태로 돌아간다.
2. **변환**: 서버가 해당 페이지를 가져와 defuddle로 본문만 Markdown으로 추출한다. 진행 중에는 로딩 상태를 보여 준다.
3. **결과 확인**: 결과 영역 맨 위에 페이지 제목과 저자 헤더가 있고, 그 아래에 Markdown을 렌더링한 본문이 나온다. 저자 정보가 없는 페이지는 저자 줄만 생략한다.
4. **내보내기**
   - 복사하기: Markdown 원문을 클립보드에 복사한다.
   - .md 다운로드: Markdown 원문을 파일로 내려받는다. 파일명은 페이지 제목에서 만든다.
   - ChatGPT로 열기 / Claude로 열기: 선택한 프롬프트(있으면)를 본문 앞에 붙여 해당 서비스의 새 대화로 보낸다.
5. **프롬프트**: 프리셋 `요약해줘`, `한국어로 번역해줘`, `쉽게 설명해줘`와 `직접 입력`이 같은 선택 그룹에 있다. 처음에는 아무것도 선택되어 있지 않다(프롬프트 없이 본문만 보낸다). `직접 입력`을 고르면 텍스트 입력창이 나타난다. 직접 입력한 문장은 그 변환 세션에서 1회용이며 저장하지 않는다.
6. **다크모드**: 헤더의 토글로 라이트/다크를 바꾼다.

## 승인된 범위

- 단일 화면(URL 입력, 결과, 내보내기, 프롬프트 선택, 다크모드 토글).
- 서버 측 페이지 가져오기와 변환.
- UI 문구는 한국어.

## 인수 기준 (관찰 가능)

1. 문서형 페이지 URL(예: `https://stephango.com/saw`)을 넣으면 제목 `Use the saw, fear the saw`와 저자 `Steph Ango`가 헤더에 나오고, 내비게이션·광고가 빠진 본문이 렌더링된다.
2. 저자가 없는 페이지(예: `https://example.com`)도 오류 없이 제목과 본문이 나오고, 저자 줄은 보이지 않는다.
3. 지우기 버튼을 누르면 입력창, 결과, 오류 메시지, 직접 입력 문장이 모두 비워진다. 프롬프트 선택도 처음 상태(선택 없음)로 돌아간다.
4. `복사하기` 후 클립보드에 렌더링 전의 Markdown 원문이 들어 있다. 프롬프트는 포함되지 않는다.
5. `.md 다운로드`로 받은 파일 내용이 Markdown 원문과 같고, 프롬프트는 포함되지 않는다.
6. 프롬프트를 고르지 않으면 열기 동작에 본문만 전달된다. 프리셋을 고르면 그 문장이, 직접 입력을 고르면 입력한 문장이 본문 앞에 붙는다. 직접 입력을 선택했지만 비어 있으면 프롬프트 없이 보낸다.
7. 프롬프트와 본문을 합친 길이가 주소 길이 한도 안이면 ChatGPT·Claude의 새 대화가 새 탭에서 열리고 내용이 입력창에 채워져 있다.
8. 합친 길이가 한도를 넘으면 프롬프트와 본문을 합친 전체 텍스트를 클립보드에 복사한 뒤 빈 새 대화를 열고, 화면에 "클립보드에 복사했습니다. 붙여넣기(Ctrl+V)하세요" 안내를 보여 준다. 본문은 잘리지 않는다.
9. 다음 입력은 각각 변환 실패로 처리되고, 이유를 구분해 알려 주는 오류 상태가 나온다(상태 전환 후에도 입력값은 유지된다).
   - URL 형식이 아니거나 http/https가 아닌 주소
   - 로컬·사설 네트워크 주소(예: `localhost`, `127.0.0.1`, `10.x.x.x`, `169.254.x.x`)로 연결되는 주소
   - 페이지를 가져오지 못함(연결 실패, 404, 시간 초과)
   - 본문을 추출했지만 사실상 비어 있음(스크립트로만 그려지는 페이지 등)
10. 다크모드 토글이 동작하고, 새로고침해도 마지막 선택이 유지된다. 처음 방문 시에는 운영체제 설정을 따른다.
11. 좁은 화면에서도 입력, 결과, 내보내기 동작이 숨겨지지 않고 위에서 아래로 쌓인다.
12. 로딩, 오류, 빈 상태, 성공 상태가 모두 같은 컴포넌트 문법으로 표현된다.
13. 모든 화면과 상태가 승인된 프로토타입의 아이소매트릭 스타일(블록 면, 바닥 격자, 일러스트)을 따르고, 글자 그림자는 URL 입력창의 입력 텍스트에만 있다. 라이트와 다크 모두 같다.

## 확정된 제약과 이유

- **변환은 defuddle 라이브러리로 한다.** 사용자 지정 사항이다. 호스팅 API(`defuddle.md/...`)가 아니라 라이브러리를 직접 쓴다. 이 프로젝트 환경과 같은 조건(Node 서버 + linkedom)에서 `https://stephango.com/saw`의 제목·저자·본문, `https://example.com`의 제목·본문, 빈 문서의 단순 결과가 정상 추출되는 것을 임시 폴더에서 확인했다(defuddle 0.19.6).
- **페이지 가져오기는 서버에서 한다.** 브라우저에서 임의의 사이트를 직접 가져오면 CORS에 막힌다.
- **서버가 임의의 주소를 가져오므로 내부망 접근을 막는다.** 로컬·사설·링크 로컬 대역으로 향하는 요청은 리다이렉트를 따라간 뒤의 주소까지 포함해 거부한다. 서비스가 서버 내부 자원을 읽는 통로가 되면 안 되기 때문이다.
- **긴 글은 클립보드 우회로 처리한다.** 사용자가 선택했다. 본문이 잘리지 않는 쪽을 택했고, 대신 붙여넣기 한 번이 더 필요하다.
- **프롬프트는 "열기"에만 붙는다.** 복사하기와 다운로드는 항상 Markdown 원문만 다룬다. 사용자가 프롬프트를 열기 흐름에서만 언급했다.
- **직접 입력은 저장하지 않는다.** 사용자 지정 사항이다.
- 렌더링된 Markdown에 포함된 원시 HTML과 스크립트는 실행되지 않는다. 임의의 외부 페이지 내용을 그대로 화면에 올리기 때문이다.

## 가정 (덮어쓸 수 있음)

- 처음 상태의 프롬프트는 "선택 없음"이다. 사용자가 "선택적으로"라고 했다.
- ChatGPT는 `https://chatgpt.com/?q=…`, Claude는 `https://claude.ai/new?q=…` 형식의 미리 채우기 주소를 쓴다. 미리 채우기가 동작하지 않거나 주소 형식이 바뀌면 인수 기준 7이 깨진다(위험 참고).
- `https://`가 없는 주소(예: `stephango.com/saw`)는 자동 보정하지 않고 형식 오류로 처리한다. 프로토타입 검토에서 이 동작을 그대로 승인했다.
- 주소 길이 한도는 구현에서 보수적인 값 하나로 정하고, 두 서비스에 같은 값을 쓴다.
- 페이지 가져오기에는 합리적인 시간 제한과 응답 크기 상한을 둔다(구체 값은 구현에서 정한다). HTML이 아닌 응답은 변환 실패로 본다.
- 파일명은 제목에서 파일 시스템에 쓸 수 없는 문자를 뺀 것이고, 제목이 없으면 도메인을 쓴다.
- 로그인이 필요한 페이지, 페이월 뒤의 글, 스크립트 실행 후에야 내용이 생기는 페이지는 지원하지 않는다. 가져온 정적 HTML에서 본문을 못 뽑으면 위 오류 상태로 처리한다.
- 변환 결과는 저장하지 않는다. 같은 URL을 다시 변환하면 매번 새로 가져온다.

## 범위 밖과 이유

- 사용자 계정, 변환 기록, 즐겨찾기: 저장하지 않는 서비스로 시작한다.
- 여러 URL 일괄 변환, 브라우저 확장, 외부용 공개 API: 요청에 없다.
- 프롬프트 직접 입력의 저장과 프리셋 편집: 사용자가 1회용으로 정했다.
- ChatGPT·Claude 외 다른 서비스로 열기: 요청에 없다.
- 호스팅 defuddle API 사용: 라이브러리 사용이 필수 조건이다.

## 남은 위험

- 미리 채우기 주소(`?q=`)는 두 서비스의 비공식 동작에 기대고 있다. 서비스가 형식을 바꾸면 열기가 빈 대화로 열릴 수 있다. 클립보드 복사를 항상 함께 해 두는 대안은 채택하지 않았다.
- defuddle은 사이트마다 추출 품질이 다르다. 일부 페이지에서는 본문이 일부 빠지거나 불필요한 블록이 남을 수 있다.
- 서버가 외부 주소를 가져오는 구조라 내부망 차단 규칙에 빈틈이 있으면 SSRF가 된다. 리다이렉트와 이름 해석 이후 주소까지 검사하는 것이 핵심이다.
- 아이소매트릭 블록 질감은 shadcn 컴포넌트를 그대로 쓰는 것만으로는 나오지 않는다. 공통 variant로 입히지 않고 화면마다 따로 만들면 `ui-composition`의 일관성 원칙과 어긋난다.
- 배포 환경(예: Vercel)의 함수 실행 시간과 응답 크기 제한이 느리거나 큰 페이지의 변환을 막을 수 있다.
